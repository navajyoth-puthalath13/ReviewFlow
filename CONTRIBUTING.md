

# Contributing to ReviewFlow

Thanks for contributing to ReviewFlow ✨

ReviewFlow is an open-source project that helps teams keep Figma review discussions visible inside Slack.

When someone comments in Figma, the message automatically shows up in Slack so the whole team can track reviews in one place.

---

# Current Idea Contributors Can Explore

## GitHub Issue Linking

One future improvement idea is GitHub issue linking.

Example:

```txt
#17-dashboard-alignment-fix - completed
```

Comment format idea:

```txt
#issue-number-task-name - status
```

Example statuses:

- completed
- in review
- in progress

ReviewFlow could:

- detect issue numbers like `#17`
- match the related GitHub issue
- send the update directly into Slack
- connect design review updates with engineering discussions

This can help teams track:

- design feedback
- issue progress
- engineering updates
- review discussions

all in one workflow.

4. Test locally
